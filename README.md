# employee-shift-manager
社員ごとの勤務日・勤務時間を管理するためのシフト管理システムです。  
**HTML / CSS / JavaScript** を使用し、ブラウザの **LocalStorage** にデータを保存する構成で開発しました。  
開発環境は **Visual Studio Code（VSCode）** を使用しています。

---

## ■ 機能一覧
- シフト登録（社員名・日付・開始時刻・終了時刻・担当・メモ）
- シフト一覧表示
- 月別フィルタ
- 社員名フィルタ（部分一致）
- 勤務時間の自動計算
- 社員別の勤務時間集計
- JSONエクスポート
- 全データ削除
- LocalStorage 保存

---

## ■ 画面構成
- **シフト登録フォーム**  
  入力後すぐに一覧へ反映されます。

- **シフト一覧**  
  日付順に並び、勤務時間を自動計算して表示します。

- **フィルタ機能**  
  月・社員名で絞り込みが可能です。

- **集計表示**  
  合計勤務時間と社員別の勤務時間を表示します。
